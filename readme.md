
# movie project
> 이 프로젝트는 스파르타의 내일배움캠프를 통해 개인과제로 제작되었습니다. 



## 1. 프로젝트 소개
-  작업기간 : 2025/01/08 ~ 2025/01/16
-  TMDB API를 활용한 영화검색사이트 제작
-  사용 기술 : html, css, javascript
-  작업자 : 이기리 

## 2. 사이트 소개
- 현재 상영중인 영화 목록을 볼 수 있습니다.
- 검색어를 입력하여 영화를 찾을 수 있습니다.
- 원하는 영화를 북마크에 저장할 수 있습니다. 


## 3. 주요기능   
- 플렉스박스를 활용한 카드 ui구현 
- 검색 : 대소문자 구분 x / Enter키를 사용하여 검색 / 디바운싱을 활용한 영화 리스트 필터링
 - 클릭한 영화의 Id를 바탕으로 상세페이지 모달 
 - 카드리스트 컨테이너에 클릭이벤트 위임
 - sync/await로 API 호출 리팩터링
